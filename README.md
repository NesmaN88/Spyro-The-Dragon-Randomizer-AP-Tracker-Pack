- Gem count Total Collect 0 to 14,000,
- Dragon Count per level,

- Egg Count per level,
- Key Placement,
- Key Chest Placement,
- Metal Chest Placement,
- Life Chest Placement,
- Egg Thief Placement,
- Gem Thief Placement,
- Key Thief Placement,
- World Realm Gates Placement.

Maps for every world and realm.
